# 🛒 Shopping Cart – Python Project

## 📌 Project Overview

This project is a **Python-based Shopping Cart application** designed to demonstrate the basic functionality and workflow of an online shopping system.

The project focuses on how customers can interact with products through a shopping cart and how input and output operations can be used to simulate an online shopping experience.

## 🎯 Objectives

* Understand the basic workflow of an online shopping system.
* Implement shopping cart operations using Python.
* Practice Python programming fundamentals.
* Work with user inputs and program outputs.
* Understand how products can be selected and managed in a shopping cart.

## ⚙️ Project Features

* Product selection
* Shopping cart functionality
* User input handling
* Program output display
* Basic online shopping workflow

## 📚 Concepts Demonstrated

This project helps demonstrate fundamental Python concepts such as:

* Variables
* Data types
* User input
* Conditional statements
* Loops
* Lists / collections
* Functions
* Input and output processing.
